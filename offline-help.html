오프라인에서 이용하기

전용 압축파일을
먼저 풀어 주세요.

GitHub Pages용 파일은 웹 주소에서 여는 방식입니다. 인터넷 없이 사용하려면 오프라인판을 내려받아 압축을 푼 뒤 그 안의 index.html을 여세요.

오프라인판 내려받기 → 이미 오프라인판을 압축 해제했다면, 현재 파일이 아니라 압축을 푼 폴더 안의 index.html을 실행합니다.

실행 순서

  1. 오프라인 ZIP 파일을 내려받습니다.
  2. 새 폴더에 압축을 완전히 풉니다.
  3. 압축을 푼 폴더의 index.html을 엽니다.
